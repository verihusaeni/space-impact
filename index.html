Cara bermain

Komputer: WASD atau panah untuk bergerak, Spasi untuk menembak, B untuk bom, P untuk jeda.

Ponsel: geser jari di sisi kiri untuk bergerak, tahan tombol Tembak (atau aktifkan tembak otomatis), ketuk Bom untuk meledakkan semua musuh.

Item: W senjata naik level, S perisai, H nyawa, B bom tambahan.

Bertahan 45 detik tiap stage, lalu kalahkan bos untuk lanjut.
